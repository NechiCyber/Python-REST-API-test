# Install

## Linux

### Clone

```bash
gh repo clone NechiCyber/Python-REST-API-test
```
### Or Use standard git clone

### Create envoriment

```bash
python3 -m venv .venv
```

### Activate envoriment

```bash
source .venv/bin/active
```

### Installing tools

```bash
pip install -r requirements.txt
```

### TO Deactivate envoriment

```bash
deactivate
```
